## About

This repository contains my individual capstone project for the
DevOps with AI Masters Program.

The project covers:

- Source Control & Collaboration
- CI/CD Pipelines
- Infrastructure as Code using Terraform
- Containerization & Kubernetes
- Observability
- DevSecOps
- Troubleshooting
- Cost Optimization

## Project Approach

This project is being implemented individually using AWS cloud
infrastructure and DevOps tools.

Detailed implementation steps, architecture, configuration,
troubleshooting notes, screenshots, and results will be documented
throughout the project.

## Development Environment

The capstone project is being developed using the following environment:

- **Cloud Platform:** Amazon Web Services (AWS)
- **AWS Region:** Asia Pacific (Mumbai) - `ap-south-1`
- **Operating System:** Ubuntu 26.04 LTS
- **EC2 Instance:** `t3.small`
- **Access:** PuTTY over SSH
- **Source Control:** Git and GitHub
- **Infrastructure as Code:** Terraform
- **Containerization:** Docker
- **Container Orchestration Tools:** kubectl and Helm
- **AWS Authentication:** IAM Role attached to EC2
